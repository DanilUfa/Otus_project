# Формат файла заявок

Сохраните файл в UTF-8, с BOM или без него. Разделитель — запятая. Первая строка должна точно совпадать с заголовком. В файле должна быть хотя бы одна запись.

```csv
RequestId,UserId,Type,StartDate,EndDate,Reason
a393aa43-15a5-45fb-9e1c-fd1059ec3601,2,Sick,2030-05-06,2030-05-07,"Два дня, по заявлению"
```

| Столбец | Правило |
|---|---|
| RequestId | Ненулевой UUID в формате с дефисами. Один идентификатор на одну логическую заявку во всех файлах одной БД импортёра. Сохраняйте его при повторе. |
| UserId | Положительный ID владельца JWT из ответа на вход. Несовпадение даёт ошибку строки. |
| Type | Одно из точных значений Annual, Sick, Unpaid. В HTTP передаётся соответствующее число 0, 1 или 2. |
| StartDate, EndDate | yyyy-MM-dd, обе даты включительно, начало не позже окончания. В HTTP это ISO 8601 в 00:00 UTC. |
| Reason | Необязательное поле до 500 символов UTF-16, без NUL. Для пустого поля оставьте завершающую запятую. |

Кавычки окружают всё поле. Внутри поля удвойте кавычку, чтобы сохранить её. В кавычках разрешены запятые и переводы строк. Окончания LF и CRLF принимаются, внутри поля сохраняется LF. Пробелы значимы. Ошибки ссылаются на первую физическую строку записи, заголовок имеет номер 1. Пустая строка между записями даёт ошибку числа столбцов.

Отсутствие файла или данных, неверный заголовок, повреждённый UTF-8, нарушенное экранирование, более 64 полей в записи и превышение лимитов файла/числа строк прерывают предварительную проверку. Job появляется только после успешной проверки. Неправильное число полей в обычной записи, ошибочные значения и отказ доменных проверок API сохраняются в ImportErrors.

Импортёр копирует вход в приватный временный файл и читает этот снимок дважды. Замена или удаление исходника после проверки не меняет обрабатываемые записи. По умолчанию пределы составляют 16 МиБ и 100 000 записей. Публикуйте готовые файлы целиком до запуска команды. Подготовка снимка ограничивает чтение по байтам даже при росте источника.

Примеры находятся в каталоге [samples](../../src/VacationPlanner.Importer/samples). Для демонстрации подставьте в примеры UserId из ответа API, если он отличается от 2.
